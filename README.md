## 🌟 About EstateX

**EstateX** is a modern Flutter-based real estate mobile application designed to make property discovery, verification, comparison, and property visits easier.

The application focuses on connecting **Buyers, Brokers, and Admins** through a simple and professional mobile experience.

> 🏠 Find Properties
> 🔍 Search & Filter
> 🛡️ Verify Listings
> 📊 Compare Prices
> 📍 Explore Locations
> 📅 Book Property Visits
